# Estradas Sucuriú

App dos mapas das estradas das fazendas (Arauco – Projeto Sucuriú). Funciona sem internet.

- Abra o link no Chrome do celular com sinal (no iPhone, Safari) e toque em **Instalar o app** na tela inicial do app. Se abriu pelo WhatsApp, antes escolha ⋮ › Abrir no Chrome.
- Depois abre sem sinal: mapa de todas as fazendas, GPS, situação dos trechos e marcação de pontos com foto.
- Os mapas se atualizam sozinhos quando o celular pega sinal.
